BEST CASE
---------
Most favorable input.

Algorithm finishes as quickly as possible.

Example: Linear Search finds target at first element.

Best Case → O(1)


AVERAGE CASE
------------
Typical/expected amount of work.

Example: Target is somewhere around the middle.

Average Case → O(n)


WORST CASE
----------
Most unfavorable input.

Algorithm does maximum possible work.

Example: Target is last or doesn't exist.

Worst Case → O(n)
