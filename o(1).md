# O(1) — Constant Time

## Definition

O(1) means **constant time**.

The number of operations does not depend on the input size `n`.

Even if `n` becomes very large, the number of operations remains approximately the same.

---

## Basic Idea

```text
Input size increases
        ↓
Number of operations stays constant
        ↓
O(1)




1.Direct array access
int x = arr[n - 1];

2.Arithmetic operation
int x = n * n;

3.fixed loop 
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}

4.fixed nested loops 
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        System.out.println(i + j);
    }
}



arr[index]       → O(1)
arr[n - 1]       → O(1)
n + 10           → O(1)
n * n            → O(1)
n * n * n        → O(1)
if condition     → O(1)
fixed loop       → O(1)
fixed nested loop → O(1)







One-Line Summary

O(1) = Constant amount of work, regardless of input size n.
